# 剃刀沼澤（經典舊世校正版）

> 適用：本戰役 Lv9–12。剃刀沼澤位於貧瘠之地南方的荊棘迷宮，是剃刀野豬人的主要據點。最終首領是卡爾加·刺肋。

## 首領與事件

| 區域 | 首領 |
|---|---|
| 荊棘入口 | 亡語者賈格巴（Death Speaker Jargba） |
| 蝙蝠洞穴 | 主宰拉姆塔斯（Overlord Ramtusk） |
| 獸欄 | 阿格姆（Agem Thorncurse，可選） |
| 深層洞穴 | 暴怒的阿迦賽羅斯（Agathelos the Raging） |
| 荊棘高台 | 盲眼獵手（稀有） |
| 最深處 | 卡爾加·刺肋（Charlga Razorflank，最終） |

原作不同補丁與資料表對次要首領的收錄略有差異；卡爾加作為最終首領與副本身份不得更改。

## 代表機制

### 主宰拉姆塔斯

- **AC／HP**：17／115。
- **野豬衝鋒**：直線 30 呎，DC14 力量，3d8+4 並倒地。
- **戰爭怒吼**：附近野豬人士兵攻擊與傷害提高，持續兩輪。

### 暴怒的阿迦賽羅斯

- **AC／HP**：16／130。
- **狂暴衝撞**：擊退目標並撞破荊棘牆，改變戰場路線。
- **低血量狂暴**：HP 低於一半時每輪多一次攻擊。

## 最終首領：卡爾加·刺肋

- **AC／HP**：16／155。
- **閃電鏈**：最多三個目標，依序造成 4d6、3d6、2d6 閃電。
- **恢復術**：每場兩次，恢復 3d8+5 HP；可打斷。
- **荊棘護盾**：近戰攻擊者承受 1d6 穿刺。
- **守衛增援**：HP 降到一半時召來兩名剃刀護衛。

擊敗卡爾加會削弱剃刀部族在貧瘠之地的威脅，但不會清除剃刀高地的天災亡靈；兩個副本必須保持獨立。
