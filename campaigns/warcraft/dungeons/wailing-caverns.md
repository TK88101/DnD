# 哀嚎洞穴（經典舊世校正版）

> 適用：本戰役 Lv4–7。入口位於貧瘠之地。納拉雷克斯試圖讓荒地恢復生機，卻在翡翠夢境中陷入噩夢；尖牙德魯伊與洞穴生物因而異變。

## 必要設定

- 納拉雷克斯是需要被喚醒的德魯伊，不是敵方首領。
- 安娜科德拉、皮薩斯、考布萊恩與瑟芬迪斯是尖牙德魯伊，不是元素領主。
- 吞噬者穆坦努斯在最後的喚醒事件中出現。

## 首領與路線

| 區域 | 首領 | 類型 |
|---|---|---|
| 地下河 | 克雷什 | 巨龜，可選 |
| 毒蛇花園 | 安娜科德拉 | 尖牙德魯伊 |
| 蛇形迴廊 | 考布萊恩 | 尖牙德魯伊 |
| 雷霆裂隙 | 斯卡姆 | 異變雷霆蜥蜴 |
| 夢境長廊 | 皮薩斯 | 尖牙德魯伊 |
| 深層神殿 | 瑟芬迪斯 | 尖牙德魯伊 |
| 根鬚之心 | 永生者沃爾丹 | 異變植物 |
| 喚醒儀式 | 吞噬者穆坦努斯 | 最終事件首領 |

變異精靈龍可作為稀有遭遇。

## 尖牙德魯伊共通機制

- **AC／HP**：14–16／70–95。
- **沉睡**：DC14 感知，失敗者沉睡一輪或受到傷害時醒來。
- **毒蛇形態**：HP 低於一半後增加移動速度，近戰附加 1d6 毒素。
- 四名德魯伊各自偏向治療、雷電、纏繞或毒素，不得合稱四大元素領主。

## 永生者沃爾丹

- **AC／HP**：17／130。
- **纏繞根鬚**：20 呎範圍，DC14 力量，失敗束縛。
- **再生**：每輪恢復 8 HP；受到火焰傷害後暫停一輪。

## 最終事件：喚醒納拉雷克斯

尖牙德魯伊首領被擊敗後，納拉雷克斯的弟子開始喚醒儀式。玩家必須護送弟子並抵禦三波噩夢生物，最後面對吞噬者穆坦努斯。

### 吞噬者穆坦努斯

- **AC／HP**：16／150。
- **吞噬**：+8，2d10+5；目標 DC15 力量豁免，失敗被吞入，回合開始受 2d8 酸蝕。
- **恐懼咆哮**：30 呎，DC15 感知，失敗恐懼一輪。
- **勝利條件**：擊敗穆坦努斯並讓弟子完成儀式。納拉雷克斯甦醒後離開洞穴，當地腐化開始減弱，但不會瞬間恢復整個貧瘠之地。
